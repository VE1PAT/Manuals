## Chapter 1 — What this equipment is

144/430 MHz FM dual-band mobile with extensive memories; common dual-band mobile.

---

## Chapter 2 — What you need for training

1. The radio (or antenna) and its normal power source / battery  
2. A suitable antenna for the band(s) in use (never key down without a proper load)  
3. For programmed radios: a programming cable / software as noted below  
4. This handbook and an Elmer for the first sessions  

**Programming / setup path:** Yaesu ADMS-2 series / cloning cable for FT-7800 where supported; manual entry for classroom basics.

---

## Chapter 3 — Learning goals

- Left/right band (V/U) operation
- Hyper Memory / memory banks
- Tone and shift
- Cross-band notes (understand legality/duty)
- Detachable face / remote mount if equipped

---

## Chapter 4 — Regional (Halifax–Dartmouth) practice notes

Program both VHF and UHF HRM machines (VE1DAR, VE1PSR, etc.).

Useful analog starting points for VHF/UHF voice training (verify tones/offsets before transmit):

| System | Approx. | Notes |
|---|---|---|
| VE1DAR | 147.150+ / 444.600+ | Dartmouth ARC |
| VE1PSR | 147.270+ / 444.350+ | Halifax ARC |
| VE1HNS | 146.940− | Halifax ARC |
| National simplex | 146.520 / 446.000 | As appropriate to the radio |

HF-capable gear: follow band plans and seek HF mentoring — not the VHF table above.

---

## Chapter 5 — Safety and good habits

1. Licence and identify legally.  
2. Lowest power that works.  
3. Know your antenna and SWR situation.  
4. Mobile installs: fuse the positive lead; secure the radio; watch RF exposure.  
5. Ask an Elmer before using advanced features (cross-band, digipeater, commercial software, etc.).

**Model-specific notes:** Cross-band repeat features must be used carefully and legally. Prefer standard repeater operation for new students.

---

## Chapter 6 — Next practice sessions (suggested)

1. Receive-only familiarization (controls, display, squelch)  
2. Simplex contact with an Elmer  
3. One local repeater memory, then a short net check-in  
4. Programming / backup of a personal training codeplug (if applicable)  
5. Optional advanced module (APRS, C4FM, HF, ATAS) once basics are solid
