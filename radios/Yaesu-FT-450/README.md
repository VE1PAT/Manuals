# Halifax & Dartmouth Amateur Radio Clubs — Yaesu FT-450

Educational materials for learning the **Yaesu FT-450** / **FT-450D**.

## Files

| File | Purpose |
|------|---------|
| [`FT-450-CW-Beacon-Aide-Memoire.html`](FT-450-CW-Beacon-Aide-Memoire.html) | Printable CW Beacon / message-keyer programming aide-mémoire (complements the OEM manual) |

## Notes

- Open the HTML in a browser and print (black-and-white friendly).
- Covers `BCN TXT`, `BCN TIM`, `CWSPEED`, and `PNL-C.S` / PLAY1–PLAY3.
- Includes the → chain-character and space / ghost-character quirks that trip up first-time beacon programming.
