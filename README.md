# Halifax & Dartmouth Amateur Radio Clubs — Manuals

Training and operating manuals for club loaner equipment and related amateur radio topics.

**Clubs:** Halifax Amateur Radio Club · Dartmouth Amateur Radio Club

## Folder layout

| Path | Purpose |
|------|---------|
| `radios/` | Radio-specific manuals (one subfolder per model) |
| `radios/DM-32UV/` | Baofeng DM-32UV loaner handbook (first radio) — see that folder’s README |
| `topics/` | Non-radio training (licensing, nets, EmComm, digital modes, etc.) |

Add a new radio under `radios/<Model>/`. Add topic manuals under `topics/<topic-name>/`.

## Branding

Document titles should identify both clubs, for example:

> Halifax & Dartmouth Amateur Radio Clubs — DM-32UV Loaner Manual

## Conventions

- Prefer Markdown sources that can be printed or exported to PDF.
- Keep each radio’s codeplug notes, checklists, and regional repeater info with that radio’s folder.
- Do not commit personal DMR IDs, passwords, or member PII.
