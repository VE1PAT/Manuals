# Halifax & Dartmouth Amateur Radio Clubs — Miracle Whip

Aide-mémoire for the portable **Miracle Whip** QRP antenna (and near-identical units such as the Moonraker **Whizz Whip**).

## Notes

- Original Miracle Whip (VA2ERY / commercial Miracle Antenna) is out of production; operating practice is sparse.
- Moonraker’s Whizz Whip instructions map closely enough for day-to-day use (PL-259, telescopic whip, tune dial, ≤10 W class).
- Keep OEM PDFs local for reference; they are gitignored and not published in this repo.
